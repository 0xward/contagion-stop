# ContagionStop — Brand Assets

Logo collection for ContagionStop, a cross-chain circuit breaker for DeFi
vaults. Everything here is a real asset used by the project or a reviewed
candidate from the same design rounds.

## Header logos — `header-logos/`

Five logo variants designed for the site header, in the Windows 98 title-bar
style of the interface. Each variant ships as an SVG source plus a PNG
render, and a second PNG showing the logo placed on the header
(`*-on-header.png`).

| File | Variant | Status |
| ---- | ------- | ------ |
| `a-raised-plaque` | Raised plaque | Candidate |
| `b-shield-pause` | Shield with pause mark | Candidate |
| `c-two-tone` | Two-tone | Candidate |
| `d-circuit-frame` | Circuit frame | Candidate |
| `e-titlebar` | Title bar | **Selected** |

The selected variant, **E — Title Bar**, is installed as the site header
logo at `frontend/public/icons/contagion-stop-logo.svg`.

## Project logo — `project-logo/`

The project mark is **B — Monogram CS**: the letters "CS" drawn on a 32x32
pixel grid. Source file: `b-monogram-cs.svg` (512x512 viewBox, 32x32 grid).

Files:

- `b-monogram-cs.svg` — vector source
- `b-monogram-cs.png` — 512x512 render
- `b-monogram-cs-16.png`, `b-monogram-cs-32.png`, `b-monogram-cs-64.png` —
  favicon sizes
- `b-monogram-cs-horizontal.svg` / `b-monogram-cs-horizontal.png` —
  horizontal lockup with wordmark

The mark is in use as the site favicon (`frontend/src/app/favicon.ico`)
and app icon (`frontend/src/app/icon.png`, 512x512).
